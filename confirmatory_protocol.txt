# Frozen follow-up on trace certificates

Locked before observing results on these operators, 11 November 2026. The stopping rules and numerical tolerances below are evaluated on new data sources. The experiment was specified before data analysis. It was conducted without external registration.

## Operators

| Source | Matrix supplied through an oracle | Settings |
| --- | --- | --- |
| [SNAP email-Eu-core](https://snap.stanford.edu/data/email-Eu-core.html) | Normalized Laplacian heat kernel on the largest connected component after symmetrizing, deduplicating, and removing loops | t = 0.5, 5 |
| [Network Repository bio-yeast](https://networkrepository.com/bio_yeast.php) | Same transform of the public protein interaction graph | t = 0.5, 5 |
| [NIST 494 BUS](https://math.nist.gov/MatrixMarket/data/Harwell-Boeing/psadmit/494_bus.html) | Inverse of real symmetric admittance matrix after scaling by the median diagonal and adding 0.01 I | one setting |
| [NIST NOS3](https://math.nist.gov/MatrixMarket/data/Harwell-Boeing/lanpro/nos3.html) | Same transform of a finite-element biharmonic operator | one setting |
| [UCI Human Activity Recognition Using Smartphones](https://doi.org/10.24432/C54S4K) | log(I + s C), where C is the Gram covariance of centered published training features divided by sample count and then by the mean diagonal. The features are used as published, with no labels. | s = 0.1, 10 |

If a source fails to download, parse, or pass operator reference checks, report the failed case and reason. Retain all other cases. The comparison contains eight fixed operators and five underlying datasets. Different settings on a source do not constitute independent datasets.

For heat kernels the experimental oracle uses an explicitly formed symmetric spectral matrix. Its trace is cross-checked against the sum of the eigenvalue transforms from an independent symmetric eigensolver, and four products are checked against sparse exponential action on the same Laplacian. For shifted inverses the oracle uses a sparse factor solve. Unit-vector solves give a trace that is cross-checked against the shifted-matrix eigenvalues. For log-covariance the oracle uses an explicitly formed symmetric spectral matrix with nonnegative eigenvalue transforms. Its trace is checked against the independent Cholesky log determinant of I + s C. All references must agree within relative tolerance 1e-8. For inverse and heat oracle product diagnostics the maximum relative discrepancy across four fixed audit probes must be at most 1e-8. References and actions are computed in floating point. The theorem applies in the exact-oracle model. The study does not convert empirical agreement into a numerical guarantee. Dense matrix setup and reference cost are separate from query accounting, so oracle counts do not establish an end-to-end speedup.

## Comparison and endpoints

All methods receive a relative target of 0.05 and failure budget 0.05. All shared-stream methods inspect interval evidence only at counts 12, 16, 24, 32, 44, 64, 96, 128, 192 and 256. Progress anchors are recorded at 4, 8, 16, 32, 64, 128, 256 with the existing schedule. Each method uses the same running hard lower bound from the full prefix sketch. Query vectors are shared across anchored and single-anchor progress, observed-norm evidence, the hybrid with a 0.025 + 0.025 split, rank-one chi-square evidence, and the split methods. The split observed-norm and split Chernoff rules share the pre-existing candidate fractions 0.25, 0.5 and 0.75 and spend risk uniformly over the 30 (fraction, checkpoint) pairs. All split methods reuse products from the common stream. A-Hutch++ Algorithm 2 with an independent lower pilot is secondary because its three phases report at completion, with a possibly different query count. Its pilot sizes, risk split, and heuristic are those from the development implementation. Its random streams are independent of the shared-stream methods.

Use 96 fresh Gaussian paths for each operator. Shared-stream seeds are fixed by `2500000 + 1000*case_index + path_index` for case indices 0 through 7 in the table order, and A-Hutch++ uses a disjoint seed offset of 1000000. No tuning on these paths. Continue replay to query 256 to assess checkpoint coverage. Record the first target crossing, center error there, terminal interval, and any exclusion of the reference over the path. Numerical exceptions are recorded separately and never silently dropped. A result is counted as a completion only if the method returned a target crossing before any numerical error. A failed later replay invalidates claims about full-path coverage, but does not erase a crossing that would have returned before that failure. A nonsuccessful run contributes the cap to the restricted query burden. At each checkpoint, stop only on a positive, finite, nonempty interval with relative radius at most 0.05. A-Hutch++ contributes actual query count on completion and the cap on all other outcomes. An incorrect completion is reported regardless of its cost.

The primary contrasts are anchored progress versus chi-square and anchored progress versus split observed-norm. Report per-operator completion rates, 256-query restricted mean cost, paired mean differences, paired win/tie/loss counts, and exact two-sided binomial sign tests on non-ties. Holm adjust the two contrasts across eight operators, keeping missing comparisons in the multiplicity budget. The sign test addresses directional wins conditional on non-ties, not equality of means. Report 5,000 paired percentile bootstrap intervals for mean differences by operator, as descriptive intervals. Report one-sided exact 95% upper bounds for observed pathwise coverage failures on paths with complete replay, alongside numerical failure counts. Path exclusions among incomplete replays are also counted separately. No inference beyond these operators follows from independent random draws on each operator. The baseline comparisons and oracle cost discussion are secondary, as are the single-anchor and observed-norm ablations.
